# Интернет-дүкен ақпараттық жүйесі

Бұл репозиторийде интернет-дүкен ақпараттық жүйесінің жобалық құжаттары сақталады.

## Жобаның мақсаты
Адамдарға үйден шықпай-ақ қажетті тауарларды ыңғайлы түрде іздеуге, таңдауға және сатып алуға мүмкіндік беру.

## Негізгі пайдаланушылар
- Клиент
- Сатушы
- Курьер
- Дүкен иесі
