## UC-01: Тауарларды іздеу
**Actor:** Клиент

**Бастапқы шарт:** Клиент интернет-дүкен жүйесіне кірген.

**Негізгі сценарий:**
1. Клиент іздеу жолағын ашады.
2. Клиент қажетті тауардың атауын енгізеді.
3. Клиент іздеу батырмасын басады.
4. Жүйе енгізілген атауға сәйкес тауарларды іздейді.
5. Жүйе табылған тауарлардың тізімін көрсетеді.
6. Клиент қажетті тауарды таңдайды.
7. Жүйе таңдалған тауар туралы ақпаратты көрсетеді.

**Нәтиже:** Клиент қажетті тауарды тауып, оның ақпаратын көре алады.
